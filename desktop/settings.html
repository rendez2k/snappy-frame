Global hotkeys

Region — freeze the screen and drag a rectangle.

Active window — grab the focused window instantly, no dragging. Files under the app's name.

Whole screen — the screen your cursor is on, grabbed instantly with no rectangle to drag.

All monitors — every screen stitched into one image, laid out the way they are on your desk. Empty for none.

Google Photos — drag a rectangle and it goes straight into your Google Photos library. Empty for none.

Idea board — drag a rectangle and it goes straight to your AI Launchpad board. Empty for none.

Mark up — drag a rectangle, then draw on it: pencil, line, arrow, box, filled box, ellipse, highlighter, text, numbered steps, pixelate and blur. Great for flagging a fix to paste into a chat.

Add to batch — collect several grabs, then save them all to a folder (drag them into a chat together) or stitch them into one image.

Capture bar — a floating bar with every mode as a button, an Options menu and a self-timer. Use it when you'd rather see the choices than remember a hotkey.

Session shelf — a slim strip of this session's snaps you can drag straight into Claude Desktop, Slack or an editor.

Copy text — drag a rectangle over anything on screen and its text lands on the clipboard instead of a picture, with API keys redacted. Uses the OCR engine built into Windows.

Pin on top — drag a rectangle and it floats above every window as a reference you can keep in view. Scroll to resize, F to dim it, Esc to close.

Terminal text — grab the focused PowerShell / cmd / Windows Terminal window's entire scrollback as text and open it in Snappy Frame as a crisp code card.

🔒 API keys & secrets

Screenshots of terminals are the usual way keys leak into a chat. Text captures mask them automatically; pixels can't be masked, so the app steers you to the safe path instead.

🔎 Text recognition (OCR)

Windows is the built-in engine: instant, free, and the image never leaves your PC. Claude reads screenshots far better — dark mode, gradients, code, tables, layout — but it uploads the image, so anything sensitive in the grab leaves your machine before the key-redaction can run. Roughly 1–2p per capture.

Google Photos (optional · uploads)

A hotkey that puts a capture straight into your Google Photos library. Google closed the old "back up this folder" routes, so this talks to the Photos API with your own Google client — the app can only add photos, never read your library.

One-time setup (about five minutes)
  1. Open console.cloud.google.com and make a project.
  2. APIs & Services → Library → enable Photos Library API.
  3. OAuth consent screen → External → fill in the basics → add yourself as a user. Publish it when you're done: while it says Testing, Google expires the sign-in every 7 days.
  4. Credentials → Create credentials → OAuth client ID → Desktop app.
  5. Paste the client ID and secret below, then press Connect.

Google will warn that the app is unverified — it is yours and unpublished to anyone else, so choose Advanced → Go to Snappy Snap. Only the "add to library" permission is requested.

Online inbox (optional · uploads)

Also send each snap to your web inbox. Get a code at snappy-frame.netlify.app/inbox and paste it here. This is the only time an image leaves your PC.

The same code powers share links: right-click a shelf thumbnail (or press Link on a pin) to upload it and copy a public link. Anyone with the link can view that one image; it expires after 7 days and the upload is deleted with it.
